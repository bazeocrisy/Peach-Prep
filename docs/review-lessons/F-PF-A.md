## MUST
- [SK-FF1d-T1] The other Test items give away both answers to this 2-point item. SK-FF1d-T2 says "In paragraph 4, Ava read the word crown" and SK-FF1d-T3 says "In paragraph 1, Ava read the word squirrel". Those are exactly the two keyed sentences (p2:4:1 and p2:1:2). In Test mode the child can move freely and go back before turning in (player.js: "Move freely, then submit"; the q-prev button shows in test). So a child who reads ahead gets 2 of the test's 6 points for free, which is a third of the mastery score. Fix: use a separate passage, or a separate misread, for T2/T3 so they never name a T1 sentence. For example, give p2 a third misread sentence used only by T2/T3 and keep T1's two targets unnamed. Or make T2/T3 standalone sentences in `stem` with `passages: []`. (Practice P1–P3 have the same overlap, but Practice has no Back button and P1 comes first, so it is fine there.)

## SHOULD
- [SK-FF1d-P1 why] The walk-through says "you put honey, not money, on pancakes". That names the answer to SK-FF1d-P3, the very next dropdown item, which asks for that word. Fix: "You cannot heat a plan, and money is not something you put on pancakes."
- [3.F.F.1.a Test] The Test reuses words from Practice and Learn, so it checks memory, not mastery (§8). SK-FF1a-T3 keys friend and laugh, which are the same two keys as SK-FF1a-P4; friend is also Learn example 1 and the Teach trick. SK-FF1a-T5's error, "anser", is a distractor in SK-FF1a-P4. SK-FF1a-T4 uses the same though/through/thought set with the same key, through, as Learn example 2. Fix: use new words in the Test, for example T3 with "answer"/"build" or "busy"/"enough"→ pick words not in Practice; T5 with a misspelling of "once"/"where"/"two" not used elsewhere; T4 with another look-alike set such as "their/there/they're" or "were/where/wear".
- [3.F.F.1.a items] All 10 items test whether a spelling is correct (encoding). The standard is about reading sight words "in isolation and in context, with accuracy and automaticity". Only SK-FF1a-T4 asks the child to read a word in context. The Teach section is about reading, so the items drift from it. Fix: swap two or three items for reading-in-context formats. For example: "Which word completes the sentence?" with look-alike sight words (was/saw, where/were, from/form), or a hottext item that asks which sentence uses the wrong look-alike word.
- [3.F.P.4.b split items: SK-FP4b-P1, SK-FP4b-P5, SK-FP4b-T1, SK-FP4b-T4] Every split question has a one-letter split as a distractor: "m / uffin", "m / usic", "w / agon", "h / elmet", "r / obin". A lone consonant is not a syllable, and a child sees that at once. So the mc items are really three-choice and the dropdowns two-choice. Fix: replace them with splits a child might really make. Examples: "mu / ffin" style splits that break a doubled letter elsewhere, a split after a blend ("hel / met" vs "helm / et" vs "he / lmet" vs "helme / t" is weak; better "hell / met"), or a split that ignores the open/closed rule ("ro / bin", which is already there; add "robi / n"). At a minimum, each distractor should give every part a vowel.
- [Tests mirror Practice: SK-FP4a-T4 vs P4, SK-FP4b-T3 vs P2, SK-FP4c-T4 vs P4] Each of these Test items copies its Practice item's template one-for-one. 4a-T4: the same "The g in __ sounds like __" two-slot dropdown, a soft g then a hard g, with the same three options. 4b-T3: the same four columns, and each row is a swap of the Practice row (she→we, bike→hope, coat→seed, fork→storm). 4c-T4: the same four columns, filled in the same order of rules. A child can answer by matching shapes rather than applying the rule. Fix: vary at least one Test item per lesson. For 4b-T3, use words where the syllable type sits in a longer word ("napkin", "pony", "railroad"), or have two rows share a column. For 4c-T4, put two rows in one column and leave "no change" empty. For 4a-T4, ask about soft and hard g in a different format, such as ms ("Which TWO words have a g that sounds like j?").

## NIT
- [SK-FP4a-P4 why, SK-FP4a-T4 why] "sounds like the j in jam, because i comes right after it" states the rule as if it always holds. Teach rightly says "often" and lists get, give and girl. Fix: "because i comes right after it, and g is often soft before e, i or y."
- [SK-FF1d-P3 clue] "Think about what people put on top of pancakes. The right word ends the same way as money." Together these leave only honey, because neither monkey nor many is a food. The clue is close to the answer. Fix: keep only the strategy: "Which word would make sense on top of pancakes? Check that it looks like money."
- [SK-FP4c-P6] The distractor "ant" is too easy to rule out for a "base word" question. Fix: replace it with "plan" or "replan".
