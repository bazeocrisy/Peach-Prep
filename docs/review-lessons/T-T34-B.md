## MUST
- [SK-TT4b-P1] There is more than one defensible answer. In stanza 3, the pair "cold" / "red" fails to rhyme, but the prompt asks only which line "does not follow his rhyme pattern". Rhyme goes both ways, so an adult could defend choosing line 1 ("The sun sinks low, the air is cold,", p1:3:1, which is a target): changing "cold" to "bed" or "head" fixes the pair just as well. The key works only by an unstated rule that the second line of a pair is the faulty one. Fix: reword the prompt to "In one pair of lines, the second line does not rhyme with the line before it. Which line is it?" Or remove p1:3:1 from `targets`. The first fix is better, because it keeps the item about the pattern.
- [SK-TT4b-T1] The same problem. In stanza 2, "blue" (line 2, p2:2:2, a target) and "away" (line 4) fail to rhyme. Choosing line 2 is defensible, because changing "blue" to "gray" would rhyme with "away". Fix: reword the prompt to "Which line does not rhyme with the earlier line it should match?" Or remove p2:2:2 from `targets`.

## SHOULD
- [SK-TT4a-P2] The clue does most of the item. It lists all four end words ("rain, yard, up, hard") and asks which two sound alike, which leaves only hearing yard/hard. Fix: "Read the last word of each line in stanza 2 out loud. Which two end with the same sound?" Do not list the words.
- [3.T.T.3.c Teach, point 3] "Because joins a reason to the why behind it" is confusing for grade 3, since a reason already *is* the why. The lesson's own uses conflict with it. The Teach example uses because to join a reason to its example. P3 uses it to join a reason to its explanation. The standard frames because as linking the opinion to its reasons. Fix: "Because joins your opinion or a reason to the facts that explain it."

## NIT
- [SK-TT3c-P3 why] "But shows something different, or gives a choice, and until tells time" reads as one clause about *but*. Fix: "\"But\" shows something different, \"or\" gives a choice, and \"until\" tells time."
- [SK-TT4b-T2] The key "But misses! Off it flew." shifts to the past tense in a stanza written in the present ("zips", "shoots"). It is acceptable in poetry, but "But misses! Off it flew" may read oddly to a child. Consider: "But misses! Off it flew" → "It misses! Off it flew." (still past), or accept it as it is. No key change is needed.
