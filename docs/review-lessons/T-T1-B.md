## MUST
- [SK-TT1a-T2] The clue gives away the answer. "People sometimes fidget with their hands when they have a worried feeling" states the inference outright, so worried leads straight to the key "nervous". It is a test item, but the clue still appears through Show me how in review (player.js step 1). Fix: "Look at what Priya sees just before she does this. Think about how you might feel standing there."

## SHOULD
- [SK-TT1a-T3 Part B] Dev's line ("You don't have to go," her brother Dev said.) is plainly not "from the end of the story", so the prompt rules it out by itself. The quote marks are also uneven: two choices have outer quotation marks and two (including the key) do not. Fix: use a late-story distractor such as "She popped up with a huge grin." (it shows feeling too, so check it does not become a second key; "She climbed the ladder one step at a time without looking down." is safer). Format all four choices the same way.
- [3.T.T.1.b Teach] "Every story has the same four parts" is an overclaim. The Teach also never says how the parts *function in the plot*, which the standard's text asks for. It only says what each part is. Fix: change "Every story has" to "Most stories have". Add a point such as "The problem gets the story moving. The events in the middle are the character trying to fix it. The solution brings the story to an end."
- [SK-TT1b-T1] The distractor "the librarian's helper" names someone who is not in the story, so the child can drop it at once. Fix: use a real but minor element, for example "Omar's teacher" or "Omar's sister". Better still, use another figure the story mentions that the child might wrongly pick.
- [SK-TT1b-T5] The column "Ending" is never taught. Teach defines the solution as "how the problem is fixed by the end". The problem is "a book that is due the next day", so returning it on time (row 3) can be defended as the Solution as well. The child can only sort it by elimination, because each column is used once. Fix: replace the "Ending" column with "Setting" (row: "Omar's home on a Thursday afternoon"). Or add a Teach point that sets the ending (how things turn out) apart from the solution.
- [3.T.T.1.c Teach] The standard names traits, motivations, actions, *thoughts* and feelings, but the Teach never mentions thoughts. SK-TT1c-P3 then tests Marisol's thoughts. Fix: add a point such as "A character's thoughts tell you what is going on inside their head, like worries or plans, and they can explain why the character makes a choice."
- [SK-TT1e-T4] If the three sentences go in "after sentence 9", the fish is released before sentence 10 describes it. That puts sentence 10 ("It was big.", or the T3 replacement "It was as long as my arm…") after the fish is already gone, so the order the item teaches breaks the draft. Fix: change the prompt to "after sentence 10".
- [3.T.T.1.e Test vs Practice] Test items T1–T5 copy P1, P2, P3, P4 and P6 one for one, down to the same kinds of distractors. Both beginning keys start with "I never…". Both detail items use a "very nice…" distractor, an all-animals fact and an "it was the kind/same…" choice. Both endings use "a new event", an animal fact and "the story is over". A child can match the patterns instead of using the skill. Fix: vary the test keys and distractors. For example, use a question or a sound word for the T1 beginning (not "I never…"). In T3, give a distractor that is specific but off-moment (such as a detail about the boat) in place of "very nice, very big".
