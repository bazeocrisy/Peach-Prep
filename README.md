# Peach Prep

Free practice for the **Georgia Milestones Grade 3 English Language Arts** test, plus a parent guide that maps every Grade 3 ELA standard.

**Live site:** https://bazeocrisy.github.io/Peach-Prep/ (GitHub Pages, `main` branch)

Peach Prep is independent. It is not affiliated with or endorsed by the Georgia Department of Education (GaDOE). Every passage and question is original practice material, not an actual test item.

## What's in it

| Section | Contents |
|---|---|
| Reading (Interpreting Texts, 34 of 60 points) | Text sets: stories, a poem, informational articles (including paired texts) and an opinion piece |
| Writing (Constructing Texts, 26 of 60 points) | Opinion essays from two sources (Read, Plan, Write, Writer's Checklist, then a parent scores with the rubric and sees a model essay); revising sets |
| Language | Grammar (Master and Reinforce rows of the GUM chart only, since the blueprint tests only those, and only in the writing part) and vocabulary |
| Practice Test | A shortened, blueprint-shaped form (24 questions, 31 points, no essay; the real test has 60 points with an essay). No hints during the test; "Show me how" afterwards |
| Parent guide | The test at a glance (from the August 2025 blueprint), every standard with GaDOE's DRAFT achievement level descriptors (October 2025; may change after standard setting) and where to practice it, the essay rubric in plain words, and a plan for using the site with GaDOE's Experience Online |

**Question types:**
- multiple choice
- multiple select
- two-part evidence (Part A / Part B)
- drop-down
- hot text
- order
- match

Scoring follows `docs/SPEC.md` §5, including partial credit on 2-point items.

**Practice mode:** "Help me" works in three steps:
1. The strategy clue.
2. A narrowing step for the format that never gives the answer away.
3. A walk-through, after which the child still chooses the answer.

## Structure

- `index.html`, `css/styles.css`: static site, no build step.
- `js/pp.js`: the namespace, set and task registry, and passage references.
- `js/engine/items.js`: the 7 item types (render, score, hints, review text).
- `js/engine/player.js`: Practice and Test runner.
- `js/skills.js`: the home skill catalog, skill pages (lesson steps), progress (this device only) and the everyday-habits page.
- `js/writing.js`: the writing-task screen.
- `js/parents.js`: the parent guide.
- `js/app.js`: screens, addresses (`#reading`, `#play/<set>/<mode>`, `#write/<task>`, `#parents/<tab>`) and the leave-test guard.
- `js/data/`:
  - `site.js`: blueprint numbers, rubric summary, the Writer's Checklist (verbatim) and sources.
  - `standards.js`: generated by `verification/gen-standards.py`.
  - `alds.js`: GaDOE's DRAFT descriptors (October 2025), verbatim.
  - `catalog.js`: the home categories, lettered groups and skill order.
  - `habits.js`: home ideas for Georgia's K-12 ELA Practices.
  - `manifest.js`: the build string and the released lessons, sets and tasks (only files listed here load).
  - `lessons/*.js`: skill lessons (`PP.addLesson`, see SPEC §8 and §8b).
  - `sets/*.js`, `tasks/*.js`: mixed practice sets, Practice Test 1 and the essay tasks.
- `docs/SPEC.md`: the content and scoring specification. Read it before writing content.

## Quality gates (every release)

1. `node verification/check-content.js`: schema, references, keys, codes, giveaways. Must report 0 failures.
2. `node verification/check-writing.js`: writing tasks.
3. Two independent reviewers per new set, a fix pass, then a final release review (`docs/review-*.md`, `docs/release-review-*.md`).
4. `python3 verification/guard.py` against `node verification/serve.js . 8350`: the browser harness, covering every item, practice, test, the parent guide, writing, navigation, and phone widths 320, 375 and 390.
5. An independent screen audit.
6. `python3 verification/readability.py`: passages at about grade 4.5 or below.

## Adding content

Write a new set file to `docs/SPEC.md`, run the gates, then add its id to `js/data/manifest.js`.
